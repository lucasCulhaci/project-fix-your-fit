# Model
## User
- (PK) ID -> Generated by the Database itself
- Username
- E-mail
- Country
- DeliveryFullName (nullable?) -> This only needs to be filled in if an item bought or sold
- DeliveryAddress (nullable?) -> This only needs to be filled in if an item bought or sold

## ClothingItem
- (PK) ID -> Generated by the Database itself
- (FK) UserID
- Title
- Category
- Brand
- Color
- Size
- Description
- ImageURLs[]

## Outfit
- (PK) ID -> Generated by the Database itself
- (FK) UserID
- ImageURL
- IsShared
- ClothingItemIDs[]

## Bundle
- (PK) ID -> Generated by the Database itself
- ClothingItemIDs[]
- Price
- Status

## Order
- (PK) ID -> Generated by the Database itself
- OrderDate
- SellerID -> UserID of the seller
- BuyerID -> UserID of the buyer
- PaymentGateway -> stripe or segno
- TransactionID -> Generated for every transaction
- (FK) BundleIDs[]
